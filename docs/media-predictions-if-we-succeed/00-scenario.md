# Media Coverage Predictions: Success Scenario

**Written:** August 2026  
**Scenario:** LICHEN launches at DEF CON/Black Hat 2027, gains traction at Burning Man, becomes "the gadget to have"

## Purpose

This directory contains predictions for how mainstream media will cover LICHEN if it succeeds. Not because we are prophets, but because media coverage follows structural patterns that are predictable once you understand the incentives.

These predictions are:
- **Falsifiable** - They are in a git repo with immutable history
- **Structural** - They describe coverage patterns, not specific events
- **Non-cynical** - Journalists are not stupid; they operate within systems

We write this down now so that when it happens, we have evidence that the patterns were knowable in advance. This is not manipulation. This is systems thinking applied to media dynamics.

## The Arc

Tech media coverage of successful open-source projects follows a predictable arc:

1. **Hacker press** - Technical publications cover the technical merit
2. **Practitioner adoption** - Niche communities actually use it
3. **Incident trigger** - A news event makes it relevant to general audiences
4. **Mainstream discovery** - Major publications run "what is this thing" pieces
5. **Moral panic** - "But what about bad actors" coverage
6. **Normalization** - It becomes boring infrastructure

Each phase has characteristic framings, publication types, and narrative structures. The following files describe each phase.

## Why This Matters

If we are right, it demonstrates that media coverage is more mechanical than it appears. If we are wrong, the record of our wrongness remains.

Either outcome is informative.
